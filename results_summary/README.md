# Results Are Withheld Pending Author Review

No result table, figure, individual-level prediction, fitted model, or dataset
is distributed in this repository.

The local analysis produces aggregate tables and figures under generated output
directories, but those files are ignored by Git. A selected result table or
figure may be added only after explicit review and approval by the author team.
The repository README therefore gives a qualitative description of the
post-QC findings without embedding numerical result tables.
